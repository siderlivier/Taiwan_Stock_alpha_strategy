# 台股多因子 Alpha 策略 (Taiwan Equity Multi-Factor Alpha)

以**免費資料**（FinMind）建構、嚴格消除前瞻偏差（point-in-time）的台股多因子選股策略。
鎖定半導體、電子、生技、金融四大產業，月頻換倉，採「產業內中性化 → 因子正交化 → 動能加權」的多因子框架。

> ⚠️ 本專案僅為量化研究與學習用途，**非投資建議**。回測績效不代表未來表現。

---

## 一、主要成果

最終策略（產業內前 10% + 動能加權，扣交易成本），對照「全池等權」基準：

| 期間 | 策略 CAGR | 策略 Sharpe | 策略 MaxDD | 基準 CAGR | 基準 Sharpe | 年化超額 | 超額 t 值 |
|------|----------:|-----------:|----------:|----------:|-----------:|--------:|--------:|
| 全期 (101 月) | 25.22% | 1.71 | −14.7% | 19.04% | 1.01 | +4.26% | 1.43 |
| 訓練期 (≤2023) | 22.93% | 1.53 | −14.7% | 17.19% | 0.90 | +3.86% | 1.09 |
| **測試期 (2024+，樣本外)** | **31.10%** | **2.21** | **−6.6%** | 23.75% | 1.33 | +5.25% | 0.93 |

三個期間都優於基準、Sharpe 全面領先、回撤約為基準一半。**誠實聲明**：測試期超額報酬的 t 值仍 < 2（未達統計顯著），主因樣本外僅 29 個月、檢定力不足；支持證據主要來自「集中度與動能加權在訓練/測試兩期一致提升」的穩健性，而非單一統計檢定。

## 二、資料來源與使用

| 資料 | 來源 | 說明 |
|------|------|------|
| 日線量價 | FinMind `TaiwanStockPrice` | 未還原 OHLCV |
| 除權息 | FinMind `TaiwanStockDividendResult` | 用於自行回推還原價 |
| 月營收 | FinMind `TaiwanStockMonthRevenue` | 含揭露時點 |
| 綜合損益表 | FinMind `TaiwanStockFinancialStatements` | long 格式（科目×期別） |
| 產業/股票清單 | FinMind `TaiwanStockInfo` | 含已下市公司 |

設計考量：
- **倖存者偏差（Survivorship Bias）**：股票池含已下市公司（如合併下櫃的勝麗 6238），下市股的價格序列會正確地停在其下市日，不會被事後剔除。
- **還原股價自製回推**：FinMind 的現成還原表（`TaiwanStockPriceAdj`）為付費會員專屬，免費版改用「未還原價 + 除權息」自行回推（見方法論）。
- **TEJ 棄用**：原規劃以 TEJ 試用帳號取財報，但其財報為 long 格式、無發布日欄位、歷史短且僅涵蓋部分公司，故改全採 FinMind；TEJ 相關腳本（`test_connection.py`、`probe_tej.py`）僅保留作診斷。

## 三、安裝與執行

```bash
pip install -r requirements.txt
```

到 [finmindtrade.com](https://finmindtrade.com) 免費註冊取得 token，複製 `.env.example` 為 `.env` 並填入：

```
FINMIND_TOKEN=你的token
```

依序執行：

```bash
python src/fetch_universe.py        # 1. 建立四產業股票池
python src/fetch_prices.py          # 2. 抓還原日價（可中斷續抓）
python src/fetch_fundamentals.py    # 3. 抓月營收 + 財報

python src/factor_eval.py           # 7. 產業內 IC/ICIR 評估
python src/mine_dfs.py              # 8. DFS 機械式因子海選
python src/backtest.py              # 9. 正交化 + 回測（最終策略）
```

## 五、方法論

### 1. 發布日對齊（Point-in-Time，最重要）

核心原則：**任何資料只能在「實際可得日」之後才被使用**，避免用到當時尚未公布的資訊。

**還原股價（後復權）**：對每個除權息事件日，調整係數為

$$ \text{factor} = \frac{\text{after\_price}}{\text{before\_price}} $$

（除權息後參考價 ÷ 除權息前收盤價）。將事件日之前的所有價格乘上各事件係數的累乘，得到還原價。並剔除 `close ≤ 0` 的停牌日，避免報酬率出現 −1／inf 假極端值。

**月營收可得日**：營收所屬月份的**次月 10 日**（法規公告期限）才視為可用（保守 lag），之後 forward-fill 到每個交易日。

**財報可得日**：以財報期末 + 法定申報期限近似公告日：

| 財報期末 | 近似公告日 |
|---------|-----------|
| Q1 (3/31) | 5/15 |
| Q2 (6/30) | 8/14 |
| Q3 (9/30) | 11/14 |
| Q4 (12/31) | 隔年 3/31 |

**對齊方式**：以 `merge_asof(direction="backward")` 把基本面對齊到每個交易日——每天只取「可得日 ≤ 當日」的最新一筆。輸出每日合併面板 `panel.parquet`。

### 2. 因子工程

由每日面板取「每月最後交易日」快照，計算月頻因子。最終採用 6 個因子（皆方向「越大越好」）：

| 因子 | 定義 | 類型 |
|------|------|------|
| `gp_to_px` | 毛利 ÷ 股價 | 價值×品質（毛利率殖利率） |
| `eps_to_px` | EPS ÷ 股價 | 價值（盈餘殖利率） |
| `op_to_rev` | 營業利益 ÷ 營收 | 獲利品質（營業利益率） |
| `g_eps_12` | EPS 年增率 | 成長 |
| `neg_vol_63` | −63 日報酬波動率 | 低波動 |
| `dist_high` | 收盤 ÷ 一年高點 − 1 | 動能 |

所有因子逐月 winsorize（1%/99% 截尾）以壓制極端值（含減資造成的假跳空）。

**DFS 機械式生成**（`mine_dfs.py`）：系統性地把基礎欄位組合成數十個候選因子（各獲利科目 ÷ 股價/營收/權益的殖利率與獲利率、營收與獲利的 1/3/12 月成長率、多期動能/波動/週轉），全部丟進下節的評估框架海選。

### 3. 因子評估（產業內 IC / ICIR）

對每個因子，**逐月、在「同產業」內**計算 Spearman 等級相關（rank IC）——即因子值與「未來 1 個月報酬」的等級相關，再跨產業平均成當月 IC。

- **rank IC（當月、單一產業）**：$ \text{IC}_t = \rho_{\text{Spearman}}(\text{factor}_t, \text{fwd\_ret}_{t}) $
- **ICIR**：$ \text{ICIR} = \dfrac{\overline{\text{IC}}}{\sigma_{\text{IC}}} $（衡量解釋力的穩定度）
- **近似 t 值**：$ t \approx \text{ICIR} \times \sqrt{N} $

**為何在產業內計算**：不同產業的基本面數值水準不同（例如金融與電子的毛利率不可比），在產業內以等級相關計算，可自動消除產業水準差異對顯著度的污染。

**防過擬合**：嚴格切**訓練期 (2018–2023)** 與**測試期 (2024–2026)**，只在訓練期海選因子，再到測試期驗證；並額外報告「各產業」ICIR，避免只在單一產業有效的因子被跨產業平均稀釋而漏掉。

### 4. 因子篩選與正交化

入選的強因子彼此高度相關（如 `gp_to_px`、`eps_to_px`、`op_to_rev` 都是「便宜又會賺」的價值/獲利維度）。採**對稱正交化（Löwdin / symmetric orthogonalization）**逐月去重：

$$ F_{\perp} = F \,(F^{\top} F)^{-1/2} $$

對稱正交化不偏向任何因子順序，把相關因子轉成彼此正交、最小旋轉的版本，避免同一維度被重複計分。綜合分數 = 正交化後因子的等權平均。

### 5. GP 符號回歸（嘗試後棄用，誠實記錄）

曾以基因規劃（自製輕量 GP 引擎，適應度 = 訓練期產業內 ICIR）搜尋非線性公式因子，並用多種子穩定性篩選對抗 GP 隨機性。結果：

- 跨種子完全不穩定，訓練 ICIR 遠低於 DFS 單因子，測試期多數翻負（過擬合）。
- 即使 warm-start（以單因子起跑）仍全數輸給單因子基準（GP 0.04–0.19 vs `eps_to_px` 0.76）。

**結論**：此資料的有效訊號本質為單調的價值/成長/低波動，GP 的非線性組合只是過擬合訓練雜訊、無法外推。為避免把不穩定帶入策略，**棄用 GP**，改採 DFS 驗證過的因子。`mine_gp.py` 保留供參考與重現。

### 6. 回測機制

每月（月底）：

1. 各因子在 (月份 × 產業) 內 z-score（產業內中性化）。
2. 對稱正交化 → 等權合成綜合分數。
3. **在每個產業內**選綜合分數前 **10%** 做多（產業中性，四產業都持有）。
4. **動能加權**：持股權重以 `dist_high` 的等級分配（動能越強權重越高）。
5. 持有一個月，月底換倉；依**換手率**扣交易成本（單次 0.4%，近似手續費+證交稅+滑點）。
6. 另計算多空組合（前 10% 減後 10%）與基準（全池等權）。

**績效指標公式**（r 為月報酬序列，年化因子 12）：

- CAGR：$ \left(\prod (1+r)\right)^{12/N} - 1 $
- 年化波動：$ \sigma(r)\times\sqrt{12} $
- Sharpe：$ \dfrac{\overline{r}\times 12}{\sigma(r)\times\sqrt{12}} $
- 最大回撤（MaxDD）：$ \min\left(\dfrac{\text{cum}}{\text{cum}_{\max}} - 1\right) $
- 超額資訊比率（IR）：年化超額報酬 ÷ 年化超額風險
- 超額 t 值：$ \dfrac{\overline{a}}{\sigma(a)/\sqrt{N}} $，其中 $ a = r_{\text{策略}} - r_{\text{基準}} $

| 期間 | 組合 | CAGR | 年化波動 | Sharpe | MaxDD | 月勝率 |

| 全期 | 多方 | 25.22% | 13.82% | 1.71 | −14.70% | 70.3% |

| 全期 | 基準 | 19.04% | 19.22% | 1.01 | −22.70% | 64.4% |

平均月換手率約 35%。多空組合偏弱（邊際在多方），且台股放空成本高，故策略以多方為主。

## 七、已知侷限

- **統計顯著性**：測試期超額 t 值 < 2，受限於樣本外僅 29 個月。
- **減資未還原**：除權息已處理，但減資（capital reduction）不在除權息表，殘留約 114 筆極端日報酬，目前以 winsorize 緩解、未根治。
- **資料起點**：受對齊期限制，資料自 2018 年起，經歷的市場循環有限。
- **基準選擇**：以「全池等權」為基準（偏小型股、本身難打敗）；未對照市值加權指數（如 0050），結果可能因基準而異。
- **多空限制**：台股放空有平盤下不得放空、借券成本等限制，多空績效為理想化估計。
