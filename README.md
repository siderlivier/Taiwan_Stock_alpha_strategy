# 台股多因子 Alpha 策略 (Taiwan Equity Multi-Factor Alpha)

以**免費資料**（FinMind）建構、嚴格消除前瞻偏差（point-in-time）的台股多因子選股策略。
鎖定半導體、電子、生技、金融四大產業，月頻換倉，採「產業內中性化 → 因子正交化 → 動能加權」的多因子框架，回測期間 **2012–2026**。

> ⚠️ 本專案僅為量化研究與學習用途，**非投資建議**。回測績效不代表未來表現。

---

## 一、主要成果

最終策略（產業內前 10% 做多 + 動能加權，扣交易成本），訓練期 2012–2019、測試期 2020–2026（含 2020 COVID 崩跌、2022 空頭、2024 多頭）：

| 期間 | 策略 CAGR | 策略 Sharpe | 策略 MaxDD | 等權基準 CAGR | 等權基準 Sharpe |
|------|----------:|-----------:|----------:|------------:|--------------:|
| 全期 (173 月) | 25.63% | 1.69 | −18.58% | 17.03% | 0.98 |
| 訓練期 (2012–2019) | 21.21% | 1.60 | −18.58% | 11.55% | 0.78 |
| **測試期 (2020–2026)** | **31.37%** | **1.80** | **−12.83%** | 24.26% | 1.18 |

**相對各市場基準的超額報酬（策略超額%，括號為 t 值）：**

| 基準 | 全期超額 (t) | 測試期超額 (t) | 基準 Sharpe | 基準 MaxDD |
|------|-----------:|-------------:|-----------:|----------:|
| 全池等權 | +6.63% (**3.29**) | +4.94% (1.37) | 0.98 | −25.17% |
| 0050（元大台灣50，含息） | +2.58% (0.43) | −0.32% (−0.03) | 1.06 | −29.19% |
| 大盤 TAIEX 報酬指數 | +5.71% (1.04) | +2.71% (0.26) | 1.05 | −25.63% |
| 櫃買 TPEx 報酬指數 | +7.98% (1.35) | +6.26% (0.59) | 0.78 | −28.24% |

**結論**：相對「全池等權」有**統計顯著的選股 alpha**（全期 t=3.29）。相對「買大盤／0050」則是**報酬打平到小贏、但風險明顯更低**（Sharpe 約 1.7–1.8 vs 大盤 1.1–1.2、最大回撤約為大盤一半）。策略的賣點是「**用更低的風險達到不輸大盤的報酬**」，而非在多頭裡比大盤更猛。

**誠實聲明**：相對市值加權大盤的「原始報酬」超額未達統計顯著（受 2024–26 大型股多頭影響）；統計顯著的 alpha 出現在「相對全池等權」的選股能力上。

| 用途 | 資料集 | 說明 |

| 除權息 | `TaiwanStockDividendResult` | 用於回推還原價 |
| 月營收 | `TaiwanStockMonthRevenue` | 含揭露時點，餵營收成長因子 |
| 綜合損益表 | `TaiwanStockFinancialStatements` | 損益表科目 |
| 資產負債表 | `TaiwanStockBalanceSheet` | 自 2012 起 |
| 現金流量表 | `TaiwanStockCashFlowsStatement` | 自 2008 起 |
| 股票清單/產業別 | `TaiwanStockInfo` | 含已下市公司（避免倖存者偏差） |

僅供績效對照的基準：0050 用 `yfinance` 的 `0050.TW`（已處理分割與配息）；大盤/櫃買報酬指數用 `TaiwanStockTotalReturnIndex`。

**還原股價**：FinMind 的現成還原表為付費專屬，免費版改用「原始價 + 除權息」自行回推（見方法論）。

**為何不用 TEJ（原本的規劃）**：本專案最初規劃以 TEJ 試用帳號取得財報，但實測後發現 TEJ 試用資料有諸多限制——財報為 long（科目逐列）格式且**缺發布日欄位**、歷史過短（月營收僅約一年）、且**只涵蓋部分公司**，對不上四產業的完整股票池。因此全面改用 FinMind；TEJ 相關腳本（`test_connection.py`、`probe_tej.py`）僅保留作為當初評估的紀錄與診斷，主流程已不使用。

**倖存者偏差**：股票池含已下市公司（如合併下櫃的勝麗 6238），下市股的價格序列會正確地停在其下市日，不會被事後剔除。

## 五、方法論

### 1. 發布日對齊（Point-in-Time，最重要）

核心原則：**任何資料只能在「實際可得日」之後才被使用**，避免用到當時尚未公布的資訊。

**還原股價（後復權）**：對每個除權息事件日，計算調整係數：

```
還原係數 = 除權息後參考價 ÷ 除權息前收盤價
還原價   = 原始價 × (該日之前所有事件係數的累乘)
```

並剔除 `收盤 ≤ 0` 的停牌日，避免報酬率出現 −1／無限大的假值。

**可得日設定**：
- 月營收：所屬月份的**次月 10 日**（法規公告期限）才視為可用。
- 財報：以財報期末 + 法定申報期限近似公告日（Q1→5/15、Q2→8/14、Q3→11/14、Q4→隔年 3/31）。

對齊方式：用 `merge_asof(backward)` 把基本面對齊到每個交易日——每天只取「可得日 ≤ 當日」的最新一筆。

### 2. 因子工程

由每日面板取「每月最後交易日」快照，計算月頻因子。最終採用 **8 個因子**（皆方向「越大越好」）：

| 因子 | 類型 | 定義 |
|------|------|------|
| `gp_to_px` | 價值/獲利 | 營業毛利 ÷ **原始股價**（毛利率殖利率） |
| `fcf_yield` | 價值/現金流 | (營業現金流 − 資本支出) ÷ 市值 |
| `bp` | 價值/淨值 | 歸屬母公司權益 ÷ 市值（淨值股價比） |
| `quality_score` | 品質 | Piotroski 風格綜合分（ROA、現金流、低應計、獲利率上升、降槓桿等訊號加總） |
| `neg_accruals` | 品質 | −(淨利 − 營業現金流) ÷ 總資產（低應計＝盈餘品質高） |
| `neg_vol_63` | 低波動 | 見下方說明 |
| `dist_high` | 動能 | 見下方說明 |
| `g_eps_12` | 成長 | EPS 年增率 |

**`dist_high`（動能）說明**：

```
dist_high = 當日(還原)收盤 ÷ 過去一年(252交易日)最高(還原)收盤價 − 1
```

這裡的「一年最高」是**過去一年的最高收盤價（價格，非報酬率）**。因為收盤不可能高於這一年的最高價，所以值恆 ≤ 0；越接近 0 代表越貼近一年高點、動能越強。

**`neg_vol_63`（低波動）說明**：

```
vol_63     = 過去 63 個交易日「每日報酬率」的標準差   (波動率, 風險指標)
neg_vol_63 = − vol_63
```

它**不是負報酬**，而是「波動率取負號」。取負是為了讓「波動越低 → 因子值越高」，對應**低波動異常**：歷史上波動較低的股票，未來報酬反而較高。

其中**市值 = 原始股價 × (股本 ÷ 10)**（面額 10 元換算股數）；殖利率/市值類因子一律用**原始股價**（非還原價），避免被各股配息歷史扭曲。所有因子逐月 winsorize（截尾 1%/99%）壓制極端值。

> 因子由 `mine_dfs.py` 以明確公式生成（約 85 個候選），再經下節 ICIR 海選與人工去重，留下上述 8 個彼此維度不同的穩健因子。

### 3. 因子評估與篩選（產業內 IC / ICIR）

對每個候選因子，**逐月、在「同產業」內**計算 Spearman 等級相關（rank IC）——因子排名與「未來 1 個月報酬」排名的相關，再跨產業平均成當月 IC。

```
rank IC  = 同產業內「因子排名 vs 次月報酬排名」的 Spearman 相關（逐月）
ICIR     = 月 IC 平均 ÷ 月 IC 標準差        (衡量解釋力的穩定度)
近似 t 值 = ICIR × sqrt(月數)
```

**在產業內計算**可消除不同產業基本面水準差異對顯著度的污染。**防過擬合**：嚴格切訓練期(2012–2019)／測試期(2020–2026)，只在訓練期海選，再到測試期驗證；要求「訓練 |t|>2、測試同方向且穩健」的因子才保留。

### 4. 因子正交化

入選因子彼此可能相關（如多個價值因子），採**對稱正交化（Löwdin / symmetric orthogonalization）**逐月去重：

```
F_orth = F × (Fᵀ F)^(−1/2)      (F 為當月標準化後的因子矩陣)
```

不偏向任何因子順序，把相關因子轉成彼此正交，避免同一維度被重複計分。綜合分數 = 正交化後因子的等權平均。

### 5. GP 符號回歸（嘗試後棄用，誠實記錄）

曾以基因規劃（自製輕量 GP，適應度＝訓練期產業內 ICIR、多種子穩定性篩選）搜尋非線性公式因子。結果跨種子完全不穩定、ICIR 遠低於 DFS 單因子、測試期多翻負；即使 warm-start 仍全數輸給單因子基準。判定為過擬合，**棄用 GP**，改採 DFS 驗證過的因子。

### 6. 回測機制

每月（月底）：

1. 各因子在 (月份 × 產業) 內標準化（z-score，產業內中性化）。
2. 對稱正交化 → 等權合成綜合分數。
3. **在每個產業內**選綜合分數前 **10%** 做多（產業中性）。
4. **動能加權**：在做多名單內，依每檔 `dist_high` 的**排名**分配權重（名次越前、權重越高），權重總和為 1。為「排名（ordinal）」配重，只看名次、不看分數差距大小（為穩健、避免離群值主導）。
5. 持有一個月，月底換倉；扣交易成本。

```
組合月報酬 = Σ(權重_i × 個股次月報酬_i) − 0.4% × 換手率
動能權重_i = rank(dist_high_i) ÷ Σ rank(dist_high)
```

報酬率採**還原價（含息總報酬）**、point-in-time，並逐月 winsorize。績效指標：

```
CAGR   = (∏(1 + 月報酬))^(12 / 月數) − 1
年化波動 = 月報酬標準差 × sqrt(12)
Sharpe = 年化平均報酬 ÷ 年化波動
MaxDD  = min(累積淨值 ÷ 歷史高點 − 1)
```

> 註：採「個股等權」配重——選股為產業中性，但持倉權重會偏向檔數較多的電子業；對照基準（全池等權）有相同傾斜，比較仍為對等。

## 六、已知侷限

- **統計顯著性**：相對市值加權大盤的原始報酬超額未達顯著（受 2024–26 大型股多頭影響）；顯著的 alpha 在「相對全池等權」的選股能力。
- **減資未還原**：除權息已處理，但減資（capital reduction）不在除權息表，殘留少數極端日報酬，目前以 winsorize 緩解、未根治。
- **資料起點**：價格/損益表可更早，但資產負債表自 2012、現金流量表自 2008，故面板以 2012 起算。
- **多空限制**：以多方為主（台股放空成本高、平盤下限制），多空組合績效為理想化估計。
- **基準資料**：2026 上半年指數出現異常大波動（多來源一致，待核對）；0050 已修正分割與單月壞點。
